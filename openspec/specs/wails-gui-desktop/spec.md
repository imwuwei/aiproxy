# wails-gui-desktop Specification

## Purpose

AIProxy 桌面 GUI（Wails）能力：为代理服务提供图形化管理界面，涵盖仪表盘、渠道管理、模型别名、模型管理、用量统计、请求日志与设置等页面，支持代理服务启停控制、服务配置管理与状态监控。

## Requirements

### Requirement: 设置页面

GUI SHALL 提供设置页面，支持配置：监听地址与端口、访问令牌、是否启用鉴权、模型刷新间隔（分钟）、代理请求超时时间、熔断阈值与冷却时长。服务配置卡片 SHALL 展示 OpenAI 兼容 API 基础地址（含 `http://` 前缀与 `/v1` 路径），并提供一键复制该地址的能力。非服务配置项变更 SHALL 立即生效并持久化；服务配置项（监听地址、监听端口、访问令牌、鉴权开关）在代理服务运行中 SHALL 不可修改，修改前必须先停止服务。

#### Scenario: 修改代理配置

- **WHEN** 代理服务已停止，用户在设置页修改监听地址或监听端口并保存
- **THEN** 设置持久化，下次启动代理服务时应用新监听地址与端口

#### Scenario: 运行中修改服务配置被拒绝

- **WHEN** 代理服务运行中，用户尝试修改监听地址、监听端口、访问令牌或鉴权开关
- **THEN** 表单锁定为只读，保存被拒绝

#### Scenario: 修改访问令牌

- **WHEN** 代理服务已停止，用户在设置页修改访问令牌并保存
- **THEN** 新令牌持久化，启动服务后新令牌生效，旧令牌失效

#### Scenario: 运行中保存非服务配置

- **WHEN** 代理服务运行中，用户修改模型刷新间隔、请求超时、熔断参数、日志保留天数或调试开关并保存
- **THEN** 设置持久化并立即生效，服务无需停止

#### Scenario: 查看并复制 API 地址

- **WHEN** 用户打开设置页服务配置卡片
- **THEN** 卡片展示当前配置对应的 API 基础地址，点击「复制」按钮可将该地址复制到剪贴板

#### Scenario: 服务配置变更后地址刷新

- **WHEN** 用户停止服务、修改监听地址或监听端口并保存后重新打开设置页（或收到状态变更事件）
- **THEN** API 地址展示更新为新配置对应的地址（含 `http://` 前缀与 `/v1` 路径）
