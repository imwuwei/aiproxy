## ADDED Requirements

### Requirement: 桌面应用与代理服务同进程

系统 SHALL 以单一桌面应用程序形式提供，GUI 与代理 HTTP 服务运行于同一进程。应用启动时 SHALL 自动启动代理服务，GUI 负责管理与监控。

#### Scenario: 应用启动

- **WHEN** 用户启动桌面应用
- **THEN** 代理服务自动启动，GUI 窗口打开并显示代理服务运行状态

#### Scenario: 应用退出

- **WHEN** 用户退出应用
- **THEN** 代理服务被停止，用量数据已持久化保存

### Requirement: 代理服务启停控制

GUI SHALL 提供代理服务启动/停止控制按钮，并显示当前监听地址与端口。

#### Scenario: 停止代理服务

- **WHEN** 用户点击停止按钮
- **THEN** 代理服务停止接受新请求，按钮变为"启动"状态

#### Scenario: 启动代理服务

- **WHEN** 用户点击启动按钮
- **THEN** 代理服务恢复监听并开始处理请求

### Requirement: 仪表盘

GUI SHALL 提供仪表盘页面，展示：今日调用次数、今日输入/输出 token 总量、启用渠道数、在线渠道数、代理地址与访问令牌等信息。

#### Scenario: 查看仪表盘

- **WHEN** 用户打开仪表盘页面
- **THEN** 页面展示今日调用次数、今日 token 总量、渠道状态与代理地址，并可一键复制代理地址

### Requirement: 渠道管理页面

GUI SHALL 提供渠道管理页面，以表格展示渠道列表（名称、厂商类型、优先级、模型数、状态、最近错误），支持新增、编辑、删除、启用/停用、连接测试与手动刷新模型操作。

#### Scenario: 渠道列表展示

- **WHEN** 用户打开渠道管理页面
- **THEN** 表格展示所有渠道及其名称、厂商类型、优先级、模型数、状态与最近错误

#### Scenario: 编辑渠道

- **WHEN** 用户在渠道列表选择渠道并点击编辑
- **THEN** 弹出编辑表单，保存后列表刷新

#### Scenario: 删除渠道确认

- **WHEN** 用户点击删除渠道
- **THEN** 系统弹出确认对话框，确认后删除

### Requirement: 模型列表页面

GUI SHALL 提供统一模型列表页面，展示所有启用渠道聚合后的模型 ID 及其支持的渠道数量。

#### Scenario: 查看模型列表

- **WHEN** 用户打开模型列表页面
- **THEN** 页面展示聚合去重后的模型 ID 及每个模型对应的渠道数

### Requirement: 用量统计页面

GUI SHALL 提供用量统计页面，支持选择日期范围（最近 7 天 / 30 天 / 自定义），展示按日汇总表（日期、调用次数、输入/输出 token）与按时段（0-23 小时）的统计表。

#### Scenario: 查看按日统计

- **WHEN** 用户在统计页选择日期范围
- **THEN** 页面展示该范围内每日调用次数与输入/输出 token 汇总表

#### Scenario: 查看按时段统计

- **WHEN** 用户在统计页选择日期范围
- **THEN** 页面展示 0-23 各时段的调用次数与输入/输出 token 汇总表

### Requirement: 请求日志页面

GUI SHALL 提供请求日志页面，表格展示最近请求记录（时间、渠道、模型、状态码、耗时、输入/输出 token、错误），支持按渠道与模型筛选。

#### Scenario: 查看请求日志

- **WHEN** 用户打开请求日志页面
- **THEN** 页面展示最近请求记录的表格

#### Scenario: 筛选请求日志

- **WHEN** 用户按渠道或模型筛选日志
- **THEN** 表格仅展示符合筛选条件的请求记录

### Requirement: 设置页面

GUI SHALL 提供设置页面，支持配置：监听地址与端口、访问令牌、是否启用鉴权、模型刷新间隔（分钟）、代理请求超时时间、熔断阈值与冷却时长。设置变更 SHALL 立即生效并持久化。

#### Scenario: 修改代理配置

- **WHEN** 用户在设置页修改监听端口并保存
- **THEN** 设置持久化，代理服务应用新配置（如运行中则重启监听）

#### Scenario: 修改访问令牌

- **WHEN** 用户在设置页修改访问令牌并保存
- **THEN** 新令牌立即生效，旧令牌失效

### Requirement: 系统托盘

GUI SHALL 支持最小化到系统托盘，托盘菜单提供"显示主窗口"与"退出"操作。关闭主窗口时应用 SHALL 最小化到托盘继续运行而非退出。

#### Scenario: 最小化到托盘

- **WHEN** 用户点击关闭按钮
- **THEN** 窗口隐藏，应用在系统托盘继续运行，代理服务保持可用

#### Scenario: 从托盘恢复

- **WHEN** 用户点击托盘菜单"显示主窗口"
- **THEN** 主窗口重新显示

#### Scenario: 托盘退出

- **WHEN** 用户在托盘菜单点击"退出"
- **THEN** 应用完全退出并停止代理服务
