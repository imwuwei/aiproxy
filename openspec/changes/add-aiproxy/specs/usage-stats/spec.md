## ADDED Requirements

### Requirement: 请求用量记录

系统 SHALL 记录每一次代理请求的用量信息并持久化。每条记录 SHALL 包含：请求时间、渠道 ID、模型、输入 token、输出 token、调用是否成功、状态码、耗时（毫秒）、错误信息。

#### Scenario: 成功请求记录

- **WHEN** 代理请求转发成功并返回响应
- **THEN** 系统生成一条包含渠道、模型、输入/输出 token、耗时与状态码的用量记录

#### Scenario: 失败请求记录

- **WHEN** 代理请求最终失败
- **THEN** 系统仍生成一条调用记录，标记失败状态并记录错误信息与状态码

#### Scenario: 流式请求 token 统计

- **WHEN** 流式请求完成
- **THEN** 系统从流式 chunk 中累计输入/输出 token 并记录

### Requirement: 按日统计

系统 SHALL 支持按自然日维度聚合统计，输出每个日期的调用次数、输入 token 总量、输出 token 总量、成功数、失败数。

#### Scenario: 查询某日用量

- **WHEN** 用户查看指定日期范围的按日统计
- **THEN** 系统返回每日的调用次数、输入/输出 token 总量、成功数与失败数

### Requirement: 按时段统计

系统 SHALL 支持按小时时段（0-23）维度聚合统计，输出每个时段的调用次数与输入/输出 token 总量，用于观察使用高峰。

#### Scenario: 查询时段用量

- **WHEN** 用户查看指定日期范围的时段统计
- **THEN** 系统返回 0-23 每个时段的调用次数与输入/输出 token 总量

### Requirement: 统计范围过滤

统计查询 SHALL 支持按日期范围过滤，并可选择按渠道、模型过滤。GUI 统计页 SHALL 提供日期范围选择（最近 7 天 / 30 天 / 自定义）。

#### Scenario: 按日期范围过滤

- **WHEN** 用户选择最近 7 天查看统计
- **THEN** 系统仅聚合该时间范围内的用量记录

#### Scenario: 按渠道过滤

- **WHEN** 用户选择特定渠道查看统计
- **THEN** 系统仅聚合该渠道的用量记录
